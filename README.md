AI Content Pipeline
AI Content Pipeline is a full-stack AI-powered social media content generation platform built using Spring MVC, JSP, MySQL, Bootstrap, and AI integrations.

The application allows users to create workspaces, generate AI-based social media content, generate promotional AI images, preview content, schedule posts, and export generated content in multiple formats.

Features-
Authentication System
- User Signup
- User Login
- Logout
- Session Management
  
Workspace Management
- Create Workspace
- View User Workspaces
- Open Workspace Dashboard

AI Content Generation
Generate platform-specific marketing content using AI.

 Supported Platforms
- Instagram
- LinkedIn
- Twitter/X

 AI Input Parameters
- Brand Name
- Brand Details
- Target Audience
- Tone
- Content Goal

AI Image Generation
Generate AI-powered promotional marketing images dynamically.

 Content Preview
Preview generated content before export or scheduling.

Content Scheduling
Schedule generated posts using date and time selection.

Export System

Export generated content as:

- PDF
- Markdown (.md)
- JSON
- ZIP
